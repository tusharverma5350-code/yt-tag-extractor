    Copy any YouTube description in full
    

    On YouTube the description is collapsed behind “…more”, and selecting it on mobile is painful. This YouTube description extractor shows the whole description exactly as the creator wrote it, with line breaks, timestamps, links and hashtags intact. You can copy it with one click or save it as a .txt file.
    

    Every URL in the description is also listed separately below it. That makes it easy to find affiliate links, sponsor links, social profiles, playlists and download links the creator shared.

    What you can learn from top descriptions
    

      

    • Keyword placement. Successful videos usually repeat their main keyword in the first one or two sentences, which is also what shows in search results.
      • 

    • Chapters. Timestamps like 0:00 Intro create chapters in the progress bar and can show up in Google results.
      • 

    • Structure. A summary, then links, then chapters, then social links, then hashtags is a common pattern.
      • 

    • Calls to action. See how creators ask for subscriptions, link to related videos and promote products.

    Frequently asked questions
    Does it get the full description?
    Yes. You get the complete description up to YouTube's 5,000-character limit, with line breaks and links preserved.

    Yes. Every URL found in the description is listed under it as a clickable link, with duplicates removed.
    Can I save the description as a file?
    Yes. Press “Save .txt” to download it as a plain text file.
    Does it work on mobile?
    Yes. The tool works in any mobile browser. Copy the link from the YouTube app's Share button and paste it here.
